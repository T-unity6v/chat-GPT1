# Study Note

自分のペースで続ける、日本語の勉強記録Webアプリ。スマートフォンとPCで利用できます。

## ダウンロードせずに使う（GitHub Pages）

初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。その後 **Actions → Deploy Study Note to GitHub Pages → Run workflow** を選ぶと公開されます。初回の有効化前に失敗した実行があっても、設定後に実行し直せます。

公開が成功した後のURL： **https://t-unity6v.github.io/chat-GPT1/**

以降は `main` へのpushでテスト・ビルド・公開が自動実行されます。Actionsの完了後、同じURLを再読み込みすれば変更が反映されます。ダウンロードは不要です。表示が古い場合は、タイマーの時間を記録してからブラウザーの再読み込みを行ってください。テストまたはビルドが失敗した場合は新しい版を公開せず、前の版が残ります。

公開するのは生成した `site/index.html` だけです。個人の学習記録はGitHubにアップロードせず、同じブラウザーに保存します。公開版への移行時は保存先が変わるため、既存の記録は旧版でJSONを書き出し、公開版の「目標と設定」で読み込んでください。アプリ本体の更新では記録を初期化しません。

GitHub Pagesが未設定の場合やリポジトリのプランで利用できない場合は、Pagesの設定を先に確認してください。ローカルで公開用の出力を作るコマンドは `npm run build:pages` です。

## 忙しい社会人向けの学習プラン

「学習プラン」から目標・教材名、目標日、ジャンル、教材全体の量、登録前に完了した量、1単位の目安時間、勉強できる曜日を登録できます。ページ・問・レッスンに対応し、プランは30件まで保存します。

「今日の一歩」で今日1日の学習時間を設定すると、残りの教材と残りの学習日から取り組む量を提案します。今日記録した学習時間を差し引き、残り時間に収まる量に制限します。1単位が残り時間に収まらない場合は、時間や目安の調整を案内します。「今日は休む」で今日の時間を0にでき、日付が変わると提案用の時間は30分に戻ります。通常の1日の目標時間とは別に、忙しい日の時間を設定できます。

提案は入力された目安時間からの計算で、教材の難しさを自動判定するものではありません。期限までに必要な量が時間に収まらない場合や期限を過ぎた場合は、日付・曜日の見直しを案内します。予定は残量と日付から毎回計算するため、休んだ日があっても再開できます。

「できた範囲を記録する」では、実際に完了した量と時間へ調整して保存できます。計画に紐づく記録の量を編集・削除すると教材の進捗も変わります。登録前に完了していた量は、プラン編集で変更できます。完了したプランも残して次の教材を追加でき、「今週を振り返る」で学習時間と日数を確認できます。計画と進捗はJSONバックアップにも含まれます。以前のバージョンの記録とジャンル設定は自動で引き継ぎます。

対象の利用者・継続収益に向けた検証方針は [開発方針](docs/product.md) にまとめています。課金機能はまだありません。

## このPCだけで使う（インストール不要）

1. GitHubの **Code → Download ZIP** でダウンロードします。
2. ZIPを展開します（Windowsでは右クリック →「すべて展開」）。
3. 展開したフォルダー内の **`portable/Study-Note.html`** をChromeまたはEdgeで開きます。GitHub上でHTMLをクリックするとソースコードが表示されるため、先にPCへダウンロードしてください。

Node.jsのインストールやサーバーの起動は不要です。このHTMLはスタイル・スクリプト・アイコンをすべて含みます。ファイルをPCの決まった場所に保存して使ってください。file URLでの保存動作はブラウザーや管理ポリシーに依存します。記録のJSONバックアップを定期的に保存してください。ファイルの移動・名前変更・別ブラウザーへの切り替え前にもバックアップし、必要なら読み込んでください。

開発者向け：ソースコードを変更したら `npm run build:portable` を実行すると、`portable/Study-Note.html` と `dist/Study-Note.html` を再生成できます。

## 開発・起動

Node.js 22以上を使用します。外部パッケージのインストール、APIキー、データベースは不要です。

```sh
cd /workspace/chat-GPT1
npm start
```

既定ポートは3000です。`PORT=3001 npm start` で変更できます。開発中のサーバー自動再起動は `npm run dev`、テストは `npm test`。画面の変更はブラウザーを再読み込みしてください。

## できること

- 科目・日付・学習時間・メモの記録、編集、削除
- ストップウォッチ、一時停止、計測時間を記録フォームへ反映（分単位、四捨五入、最小1分）
- 日別・週別・累計の学習時間、連続学習日数、目標達成率
- 記録の検索と科目別絞り込み
- 1日の目標設定
- 「目標と設定」から学習ジャンルを追加・名前変更・削除（1〜50件、名前は30文字まで）
- ジャンル左の「⠿」をマウスまたは指でドラッグして並べ替え。キーボードでは持ち手にフォーカスして↑↓で移動
- JSONの書き出しと読み込み。同じIDは追加せず、既存の記録と目標を保持

初回は空の記録から始まります。架空の実績やデモ記録は入りません。日付は利用端末の現地時間です。連続学習日数は今日、または昨日を起点として計算します。

ジャンル名を変えると、そのジャンルの過去の記録も更新します。記録があるジャンルの削除時は、移動先のジャンルを選びます。時間・日付・メモは残り、学習記録は削除しません。タイマーと記録フォーム、絞り込みにも変更が反映されます。以前のバージョンの保存データ・JSONも読み込めます。新しいバックアップにはジャンル設定を含み、読み込み時は既存のジャンルへ追加します。

並べ替えた順番は自動保存し、タイマー・記録フォーム・絞り込みにも同じ順番を使います。ドラッグ中は挿入先に緑の線を表示します。長い一覧は画面の上下端で自動スクロールします。Escキーや一覧の外へのドロップで変更をキャンセルできます。並べ替えで学習記録・時間・メモは変更しません。

## データの保存について

記録はブラウザーのlocalStorageに保存します。サーバーへの記録送信、利用状況の解析、外部フォント通信はありません。ブラウザープロファイルとサイトのURL（ドメイン・ポート）が変わると別の保存領域になります。公開するときはHTTPSを使用してください。

サイトデータの削除やプライベートブラウズ終了による消失に備え、「目標と設定」で定期的にJSONを書き出してください。複数端末の同期、ユーザー認証、バックエンドへの永続化は未実装です。同じブラウザーを利用する人から記録を隠す認証機能はありません。タイマーはページを閉じると失われるため、先に記録してください。

読み取れない保存データは上書きせず、保存を停止します。同時に複数タブで編集せず、変更後は他のタブを再読み込みしてください。JSON読込は最大10MB・10,000件までです。

## 月3,000円の収益目標に向けて

現段階は、ご自身が毎日使って改善点を見つけるための無料版です。GitHub Pagesへの自動公開設定を用意しています。課金や広告は実装していません。収益は保証されません。

1. まず2週間利用して、記録の続けやすさと必要な科目を確認する。
2. 数人に試してもらい、継続して使う理由と困りごとを確認する。
3. 要望に応じてアカウント・端末間同期を追加し、公開運用とバックアップを整える。
4. 価値が確認できた機能（長期レポート、試験日からの学習計画など）の有料化を検討する。

例えば月300円×10人で売上3,000円です。決済手数料やサーバー費用を差し引く前の金額なので、利益3,000円を目指すならその分を上乗せする必要があります。実際の課金開始前には、解約・返金対応、プライバシーポリシー、特定商取引法に基づく表記などを整備します。
