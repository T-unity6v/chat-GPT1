# Study Note の対象と開発方針

働きながら、資格や仕事に役立つ勉強を通年続けたい人に向けた、計画と記録のアプリです。

## 中心に置く利用者（検証前の仮説）

30歳の経理・事務担当。簿記2級の次はExcelや業務知識を学びたい。平日は20〜40分、休日は1時間を確保したいが、残業や家事で予定が変わる。メモ・カレンダー・教材の付箋に管理が分かれ、計画が崩れると次に何をするか決められなくなる。

「今日はできる時間で何をすればいいか」「休んだ後にどう再開すればいいか」を決めやすくすることを優先します。休息を失敗として扱わず、目標日や予定を変更できる設計にします。性別や年齢そのものより、この困りごとが実際にあるかを確かめます。

## 今回用意した体験

- 教材・ジャンル・目標日・単位・勉強する曜日・1単位の目安時間を登録する。
- 今日の合計学習時間に収まる範囲を提案し、休む日も選べる。
- 提案は残量を残りの学習日で均等に配分する。教材内容の難しさを理解する機能ではなく、本人が入力した目安時間から計算する。
- 完了した量と実際の時間を記録する。記録の修正・削除も進捗に反映する。
- 残り日数が少なすぎる場合や期限超過時は、期限や曜日の見直しを案内する。
- 達成した目標を残したまま次の教材を登録し、週末に時間と学習日数を振り返る。

## 毎月3,000円を継続するための検証

課金・広告・有料会員管理はまだありません。月500円×6人は月売上3,000円、月500円×10人は月売上5,000円です。手数料や運営費を引いた利益とは区別します。価格・継続率・需要は未検証です。

まず3〜5人に試してもらい、計画を作れたか、忙しい日の翌日に戻ってきたか、週末に見直したかを聞きます。試験が終わった後も次の学習に使うか、月500円で使いたいかを確認します。現段階で利用状況を自動送信する解析機能は追加していません。

収益化前には、ユーザーの方針に従って今後の開発用コードを非公開リポジトリと適切なホスティングへ移します。すでに公開したコードの取得済みコピーは回収できません。認証や決済の秘密情報はブラウザーへ配信しません。
